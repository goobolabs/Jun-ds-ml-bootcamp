## Final Project

### Bank Customer Intelligence System

The final project is a full-stack machine learning application that:

- Predicts whether a bank customer will subscribe to a term deposit
- Returns the prediction probability
- Assigns customers to one of two customer segments
- Provides a description of each customer segment
- Uses FastAPI for the backend
- Uses React for the frontend dashboard

The project combines:

- Supervised learning
- Unsupervised learning
- Data preprocessing
- Model evaluation
- REST API development
- Frontend and backend integration
